# AI 评测后续开发计划

> 更新于 2026-03-12。已完成模块（数据模型扩展、提交触发评测、结果展示、教师侧接入）已从本计划移除。

## 当前目标

在现有“跟读 + 听力”稳定可用的前提下，完成评测链路的生产化与对话任务衔接。

## 未完成事项（按优先级）

### P0 生产化完善

- [ ] 环境变量治理：区分 dev/test/prod，补齐缺失变量告警。
- [ ] 失败重试机制：`ai_evaluateSubmission` 增加幂等与有限重试。
- [ ] 观测与审计：记录评测耗时、失败原因、供应商响应码。

### P1 质量与验收

- [ ] 补充 V2 自动化 smoke：提交 -> 评测 -> 查询结果全链路。
- [ ] 更新 `docs/test_plan_v1.md`：新增跟读/听力评测关键用例与回归清单。
- [ ] 增加异常场景用例：无音频、弱网重试、ASR 空文本、评测超时。

### P2 与轻量对话打通

- [ ] 对话首轮和次轮都复用现有评测接口，输出每轮得分与纠错建议。
- [ ] 增加 `dialogueSessionId` 维度，沉淀“会话级”评测摘要。
- [ ] 会话结束后生成结构化反馈：问候、信息获取、应答准确度。

## 说明

- 现阶段不要求 OpenAI Realtime 直连小程序；优先采用服务端 HTTP 编排完成 1-2 轮对话。
- Realtime 接入放到后置阶段，等任务稳定和教材流程稳定后再投入。
