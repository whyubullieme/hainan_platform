## 九、V2.0 AI 评测用例

| 用例 | 步骤 | 预期 | 结果 |
|------|------|------|------|
| 9.1 正确答案+标准发音 | 提交含正确语义的音频（关键词/答案匹配） | 语义通过，发音分、总分正常显示 | ☐ |
| 9.2 正确答案+差发音 | 提交正确语义但发音不标准 | 语义通过，发音分偏低 | ☐ |
| 9.3 答非所问+好发音 | 提交与题目无关的内容 | 语义未通过，发音分正常 | ☐ |
| 9.4 噪音/静音 | 提交噪音或静音音频 | Mock 阶段有占位结果；生产需 ASR 失败处理 | ☐ |
| 9.5 超时/重复提交 | 快速重复点击提交、网络慢 | 幂等，不报错，评测仅触发一次 | ☐ |
| 9.6 评测中轮询 | 提交后停留在任务详情页 | 2s 轮询，评测完成后自动刷新显示分数 | ☐ |
| 9.7 第三方 API 失败降级 | （生产）ASR/口语评测 API 失败 | evaluationStatus=failed，仍可人工点评 | ☐ |
| 9.8 教师点评页 AI 辅助 | 教师进入批改页 | 显示语义是否通过、发音分、识别文本、错词提示 | ☐ |
| 9.9 提交记录页得分 | 学生查看提交记录 | 每条显示评测状态（评测中/失败/总分） | ☐ |
