# 下一步开发计划

> 更新于 2026-03-02，基于 V1.0 MVP 完成后的路线图

## V1.0 当前状态（准备上线）

- ✅ 学生端：登录、入班、今日任务、任务详情（跟读/朗读）、签到、标记提交、我的任务（分页）、学习进度、提交记录、老师点评
- ✅ 教师端：仪表盘概览、未完成/已完成名单、点评编辑、添加一天任务
- ✅ 管理员：创建班级（含课程天数）、班级管理、成员管理
- ✅ 任务类型：跟读、朗读（taskType 字段）
- ✅ UI 优化：统一主色为 #07c160，按钮层次清晰

## 下一步计划（按优先级）

### 1. V1.0 上线前
- [ ] 完成 V1.0 测试计划（见 `docs/test_plan_v1.md`）
- [ ] 接入 5 天真实教材内容（替换 placeholder）
- [ ] 部署所有云函数至云端
- [ ] 提交微信审核

### 2. V1.1 可选增强
- [ ] **签到功能**：接入实时位置或扫码校验（当前已 disable）
- [ ] **小程序内音频上传**：学生可录/传音频，教师在小程序内播放并点评
- [ ] 教师端：班级选择器（多班级时切换）
- [ ] 学生端：任务详情页展示具体练习文本/素材

### 3. V2.0 AI 评测
- [ ] 选定 AI 厂商（科大讯飞 / 腾讯云等）
- [ ] 接入发音评测 API
- [ ] 自动打分 + AI 点评，教师复核后反馈
- [ ] 任务详情页：录音 → 上传 → AI 评分 → 展示结果

### 4. 长期
- [ ] 高频错误统计（原 CF9 teacher_getTopErrors）
