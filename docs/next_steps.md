# 下一步开发计划

> 更新于 2026-03-12，聚焦试点阶段（任务类型仅保留：跟读 + 听力）

## 已落地基线（已从计划中移除）

- 建班 `admin init` 仅初始化听力题包。
- 占位任务（如“综合练习”“入住场景对话练习”）已从核心链路移除。
- 教师发题链路可用：`teacher_getTaskBank` -> `teacher_addDayTasks`。
- AI 评测链路可用：提交后评测、结果回写、学生/教师端展示。

## 当前未完成项（按优先级）

### P0 稳定性与发布准备（本周）

- [ ] 完成回归测试：听力会话、跟读评测、教师发题、建班初始化。
- [ ] 统一任务类型文档到 `read_along | listening_mcq`（移除 `read_aloud` 历史描述）。
- [ ] 梳理并补齐云函数部署清单，完成线上环境变量核验。

### P1 任务生产化（教材团队接入前）

- [ ] 新增任务来源标识：`sourceType`（`seed` | `teacher` | `official`）。
- [ ] 将任务库从代码常量迁移到数据库集合（支持增删改查和上下架）。
- [ ] 增加“班级发布记录”表，支持追踪是谁在何时发布了哪些任务。

### P2 轻量对话（1-2 轮）MVP

- [ ] 新增任务类型 `dialogue_turn`（或独立 session 表），先支持 1 问 1 答 + 1 次追问。
- [ ] 流程编排：
  - 学生首句语音 -> ASR + AI 评测并行。
  - 首句文本送 LLM 生成追问。
  - 学生二次回答 -> 评测 -> 结束并汇总反馈。
- [ ] UI：新增“对话任务详情页”，显示对话步骤、当前轮次、结束总结。
- [ ] 先走服务端 HTTP（非 Realtime）实现，规避大陆网络不稳定与接入成本。

### P3 Realtime 架构预研（后置）

- [ ] 自建后端中转（WebSocket）方案评估：部署地、延迟、成本、稳定性。
- [ ] 鉴权与配额：短时 token、班级级并发上限、异常降级策略。
- [ ] 与对话 MVP 共用会话模型，避免二次重构。
